# PrairieRun

PrairieRun is a browser extension for PrairieLearn. It adds a cleaner assignment view to the PrairieLearn home page and keeps assignment due dates organized in separate Google Calendars for each class.

It automatically scans your classes, shows assignment scores and due dates, and creates one-hour calendar blocks that end when assignments are due. Existing calendar events are updated instead of duplicated.
